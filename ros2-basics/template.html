ROS 2 Tutorial Additions

Nine sections to paste into the Notion ROS 2 tutorial, one per gap between the tutorial and the exam. Code sits in toggles (▸ Python / ▸ C++), like the existing pages. Every Python and C++ file was built and run on ROS 2 Humble, and the outputs shown are real.

  1. 1 Open the Notion page named on the card and find the section it goes after.
  2. 2 Click Copy for Notion, then paste on an empty line there.
  3. 3 If a toggle pastes as plain text, make an empty toggle in Notion (type /toggle) and paste that toggle's Copy code into it.
  4. 4 If a table does not paste as a table, try its Copy table button (Markdown), or switch tables to bulleted lists below.
  5. 5 Tick Pasted to track progress (saved in this browser only).
