Software courses軟體課程

Eight introductory courses and one debug clinic. Each course is one live session of about 4 hours with one worksheet. Together they give you a map of the whole robot software stack: where each piece sits, what it assumes, and how it breaks. Every course starts from what our robots really do, then goes beyond them to the robotics knowledge behind it.

八堂入門課，加一場除錯工作坊。每堂課是一次約 4 小時的現場課程，配一份學習單。全部上完，你會有一張整個機器人軟體架構的地圖：每一塊在哪裡、它假設了什麼、它會怎麼壞掉。每堂課都從我們的機器人實際在做的事開始，再延伸到背後更廣的機器人知識。

How the worksheets work. Each one opens with a puzzle: something goes wrong, you guess why, and the session explains it. The numbered Parts are what we do together. Boxes and Parts marked Go deeper are for after the session. Step-by-step walkthroughs open from the worksheet; use ← → and press E for the explanation. Every page has a 中文 button, or press L.

學習單怎麼用。每份都從一個謎題開始：某件事出錯了，你先猜原因，課程再解釋它。有編號的部分是課堂上一起做的。標成延伸的方塊和部分是課後看的。逐步解說從學習單開啟，用 ← → 前後移動，按 E 看說明。每一頁都有 English 按鈕可以切換語言，也可以按 L。

OS‑1: Files and ProcessesOS‑1：檔案與 process

Debug Clinic除錯工作坊

Can you fix a broken workspace by yourself?

你能自己修好一個壞掉的 workspace 嗎？

Hands-on, not a lecture. Each pair gets a broken ROS 2 workspace (build errors, wrong QoS, a frozen executor, a node that won't stop) and fixes it with a method: reproduce, read the error, narrow it down, check one assumption at a time. Any time after OS‑2.

動手做，不是講課。每組拿到一個壞掉的 ROS 2 workspace（編譯錯誤、QoS 不對、卡住的 executor、停不下來的 node），用一套方法修好它：重現問題、讀錯誤訊息、縮小範圍、一次檢查一個假設。上完 OS‑2 之後隨時可以參加。

Set up once, for every course設定一次，所有課程通用

Every example in every course runs in one container: ROS 2 Humble plus the tools the worksheets use. Each course's example code is in its code/ folder in this repository. On a laptop with Docker and network, do this once:

每堂課的每個範例都在同一個容器裡跑：ROS 2 Humble，加上學習單會用到的工具。每堂課的範例程式碼放在這個 repository 裡該課的 code/ 資料夾。在有 Docker、有網路的筆電上做一次：

git clone https://github.com/DIT-ROBOTICS/Robotics-Software-101.git
# or, if your SSH key is on GitHub:
git clone git@github.com:DIT-ROBOTICS/Robotics-Software-101.git

cd Robotics-Software-101
docker build -t dit-course docker/

No SSH key on GitHub yet? GitHub's guide shows how to make one and add it.

GitHub 上還沒有 SSH key？GitHub 的說明教你怎麼產生一把並加上去。

The build downloads ROS 2 (about 1 GB), so do it at home, not on the room's Wi‑Fi. Before each course, git pull to get its code, and build again if docker/Dockerfile changed. Each worksheet starts with the one command that opens its container.

建置時會下載 ROS 2（大約 1 GB），請在家裡做，不要用教室的 Wi‑Fi。每堂課之前先 git pull 拿到這堂課的程式碼；如果 docker/Dockerfile 有改，就再建置一次。每份學習單一開始都會給你開啟容器的那一行指令。
